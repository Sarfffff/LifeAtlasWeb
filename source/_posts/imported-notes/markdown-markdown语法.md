###### 自动连接：

​	Markdown 支持以比较简短的自动链接形式来处理网址和电子邮件信箱，只要是用<>包起来， Markdown 就会自动把它转成链接。也可以直接写，也是可以显示成链接形式的	   ![](markdown语法.assets/70-17193854490212.png)

​	你可以在一行中用三个以上的星号(*)、减号(-)、底线(_)来建立一个分隔线，行内不能有其他东西。你也可以在星号或是减号中间插入空格。

### 3.数学公式

###### 加减乘除

- a + b ：`$a+b$`
- a − b ：`$a-b$`
- a * b  : ` $a*b$`

- $\frac{a}{b}$  : `$\frac{a}{b}$`

###### 幂数、指数、对数

- 指数  $a^b$  :`$a^b$`
- 幂数 $x^n$  :`$x^n$`
- 对数 $\log_a^b$  :`$\log_a^b$`
- 对数 $\ln x$:`$\ln x$`
- 上标用’^’，下标用’_’;
- 如果上标或者下标不止一个符号，请用’{}'括起来；

###### 根号，省略号，向量以及特殊符号（大于等于，小于等于），划线

- $\sqrt x$:`$\sqrt x$`（根号）
- $\sqrt[n]{x}$:`$\sqrt[n]{x}$`（开n次方根）

- $\surd x+y$:`$\surd x+y$`（仅输出根号）
- $\dots $:`$\dots $`（省略号）

-  $\vec x$:`$\vec x$`（向量）
- $\to $:`$\to $`(箭头)

- $\alpha$:`$\alpha$`

- $\theta_i$:`$\theta_i$`
- $a \geq b$:`$a \geq b$ 或则 $a \ge b$`

- $a \le b$:`$a \le b$`

###### 累加，累乘

$$sum = \sum_{i=1}^n\frac{1}{x^2}$$：`$$sum = \sum_{i=1}^n\frac{1}{x^2}$$`(累加)

$$sum = \prod_{i=0}^n{1 \over {x^2}} $$:`$$sum = \prod_{i=0}^n{1 \over {x^2}} $$`（累乘）
